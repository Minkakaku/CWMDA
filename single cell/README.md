# Single Cell Analysis Code

这个文件夹是单细胞和空间分析代码的总入口，按三个层次组织：

- `R single cell/`：R 版本单细胞主流程和 R 工具。
- `Python single cell/`：Python/Scanpy 版本单细胞主流程和 Python 工具。
- `alternative tools/`：主流程之外的拟时序、通讯、CNV、空间、导出、shell 辅助脚本等。

分析结果目录可以继续放在本目录下，例如 `01_QC/`、`04_qs2/`、`06_Subcluster/`。

详细说明见：

- `R single cell/README.md`
- `Python single cell/README.md`
- `alternative tools/README.md`
