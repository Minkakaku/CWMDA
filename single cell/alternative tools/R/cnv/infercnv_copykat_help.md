# infercnv.py CopyKAT Help

This script reads `.h5ad` only. Convert the Seurat object to `.h5ad` first, then run CopyKAT from Python.

## 1. Prepare h5ad

Run:

```bash
Rscript Toh5ad.R
```

Recommended input:

```text
../04_qs2/05.sc_final.h5ad
```

Use the actual path generated by your conversion script.

## 2. Epithelial-only CopyKAT

Recommended command:

```bash
python infercnv.py \
  --input ../04_qs2/05.sc_final.h5ad \
  --species human \
  --method copykat \
  --group-column cell_type \
  --observation-mode epithelial_only \
  --epithelial-label Epithelia \
  --reference-types T,B,MAST \
  --output-dir ../06_CopyKAT_Epithelia
```

Important behavior:

- `--observation-mode epithelial_only` keeps only cells whose `cell_type` equals `Epithelia`.
- In CopyKAT mode, epithelial cells are kept, and reference cells are sampled into the input matrix by default.
- The default reference sampling is at most 500 cells per reference type and at most 5000 reference cells total.
- `--copykat-n-jobs` defaults to `1` to avoid R `mcfork()` memory spikes.
- This gives CopyKAT normal/diploid reference cells without running on the full dataset.

Your previous log showed:

```text
33138 genes, 114721 cells in raw data
Error in mcfork(): Cannot allocate memory
```

That happened because too many cells were passed into CopyKAT. With the updated script and the command above, the input should be epithelial cells plus a sampled reference set.

## 3. Reference Cell Controls

Reference cells are included by default. If you want to change the sampling size:

```bash
--max-reference-cells 5000
--max-reference-cells-per-type 500
```

To choose reference cell types manually:

```bash
--reference-types T,NK,B,Plasma,Myeloid,Endothelia,Fibroblast
```

If you want to keep all reference cells, use:

```bash
--max-reference-cells 0
--max-reference-cells-per-type 0
```

This may again require a lot of memory.

If you really want no reference cells:

```bash
--no-include-reference-cells-for-copykat
--no-copykat-normal-from-reference
```

This is not recommended for your current data because it can produce mostly `Unknown` calls.

## 4. Counts Layer

By default, the script uses:

```bash
--layer counts
```

If raw counts are stored in `X` instead of `layers["counts"]`, use:

```bash
--layer ""
```

## 5. Main Outputs

Output directory:

```text
../06_CopyKAT_Epithelia/
```

Key files:

```text
copykat_cell_calls.csv
copykat_prediction_counts.csv
copykat_on_input_umap.pdf
copykat_chromosome_heatmap_by_status.pdf
copykat_chromosome_heatmap_by_group.pdf
copykat_cnv_umap.pdf
infercnv_result.h5ad
run_summary.json
```

Important columns in `copykat_cell_calls.csv`:

```text
copykat_prediction
copykat_tumor_status
copykat_is_tumor
```

Interpretation:

- `copykat_tumor_status = Tumor`: predicted tumor cell.
- `copykat_tumor_status = Normal`: predicted normal cell.
- `copykat_tumor_status = Unknown`: uncertain prediction.

## 6. Background Run

```bash
nohup python infercnv.py \
  --input ../04_qs2/05.sc_final.h5ad \
  --species human \
  --method copykat \
  --group-column cell_type \
  --observation-mode epithelial_only \
  --epithelial-label Epithelia \
  --output-dir ../06_CopyKAT_Epithelia \
  > copykat_epithelia.log 2>&1 &
```

Check log:

```bash
tail -f copykat_epithelia.log
```

## 7. Pre-run Checks

Make sure:

- `adata.obs` contains `cell_type`.
- `cell_type` contains `Epithelia`.
- raw counts are in `layers["counts"]` or `X`.
- `X_umap` exists if you want original UMAP visualization.

If the script says no epithelial cells were found, check whether the actual label is `Epithelia`, `Epithelial`, `Epithelia cells`, or another spelling.
